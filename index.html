The idea

How MaSMS works

You install the app on your Android phone that receives SMS

1

SMS arrives

Any Android phone with a SIM card receives SMS.

2

App reads SMS

And checks your filter rules, prepares the email.

3

Email sent via API

If first API fails, app tries next API.

4

SMS arrives in inbox

Read forwarded SMS in your email inbox.

Getting started

Set up in few minutes

No Play Store. Side-load APK, fill-in email and API keys, tap Save.

1

Download the APK

Download latest MaSMS.apk file to your Android phone.

2

Enable "Install unknown apps"

Open Settings → Apps → Special app access → Install unknown apps, then allow your browser or file manager to install APKs. Open the downloaded file to install.

3

Grant SMS permission

App asks for SMS permission, tap Allow. MaSMS needs Receive, Read and Write SMS. It does not request contacts, location, camera, or microphone access.

4

In MaSMS app, click gear icon, fill in your email

Enter the email address where forwarded messages should land. This is both the sender and the recipient (you're emailing yourself).

5

Add at least one API key

Sign up for Resend, Brevo, or Sender.net (all free with daily limit). Paste the API key into the matching field in Settings. Adding all three gives you automatic fallback if one provider has an outage.

6

Tap Save, then Send test

Save your settings, then tap Send test. MaSMS will send a test email through each configured provider individually. Check your inbox if you see the test emails, you are all set.

Free email API

Getting your API keys

MaSMS uses transactional email APIs, the same technology that sends password-reset emails. All three offer a free tier more than enough for SMS forwarding.

Primary

Resend

Free tier: 100/day. Requires a verified email or domain.

  • 1 Go to resend.com and create a free account.
  • 2 In the dashboard, click Domains → Add Domain, or use the built-in onboarding email for testing.
  • 3 Go to API Keys → Create API Key. Copy the key. It starts with re_
  • 4 Paste it into the Resend API key field in MaSMS Settings.
Fallback 1

Brevo

Free tier: 300/day. Requires a verified email or domain.

  • 1 Go to brevo.com and sign up for a free account.
  • 2 Verify your sender email: Senders & IP → Senders → Add a Sender, then confirm the email link.
  • 3 Open Account → SMTP & API → API Keys → Generate a new API key. Copy the key. It starts with xkeysib-
  • 4 Paste it into the Brevo API key field in MaSMS Settings.
Fallback 2

Sender.net

Free tier: 500/day. Requires a verified email or domain.

  • 1 Go to sender.net and create a free account.
  • 2 Verify your sender: Account → Senders → add your email and confirm the verification link.
  • 3 Go to Account → API → Create API token. Copy the token. It typically starts with api_
  • 4 Paste it into the Sender.net API key field in MaSMS Settings.

Note: All three providers require you to verify the sender email address (the one you put in MaSMS Settings). You are sending email from yourself to yourself, make sure email is verified in each provider dashboard before testing.

Filter modes

Forward All or only Important SMS

Choose between two modes in the Filters screen. Swipe left on any log entry to block that sender; swipe right to mark them as important.

All SMS mode

Forward everything except blocked senders

This is the default. Every SMS is forwarded unless the sender is on your block list. Good for staying informed about all messages from an unattended phone.

Important only mode

Forward only from approved senders

Only SMS from senders on your important list are forwarded. Everything else is silently logged as BLOCKED. Good for high volume phones where you only care about specific senders.

Swipe right on a log entry adds sender to Important list · Swipe left adds to Block list. You can also add entries manually in the Filters screen.

Questions

Does it work when my phone has no internet? ›
Yes. If you configure a forwarding number in Settings, MaSMS fallsback to sending the SMS via the phone SIM when there is no data connection. You pay standard SMS rates for forwarded messages. If there is no internet and no forwarding number, the message is queued and sent as soon as the phone goes online.
Does it drain the battery? ›
No. MaSMS uses Android WorkManager, which runs only when a new SMS arrives and then stops. There is no persistent background process and no sticky notification. On most devices the battery impact is negligible.
Can I use it on more than one phone? ›
Yes. Install the APK on as many Android phones as you like. Each phone has its own settings. You can forward to the same email on all of them or to different ones.
Why do I need to verify my email with the provider? ›
Email providers require a verified sender address to prevent spam. MaSMS sends email from your own email address to your own email address (a self-send). You only need to verify it once in each provider's dashboard.
What data does MaSMS send to the cloud? ›
Only the email it sends via the API provider you chose. The SMS content, sender name and timestamp are included in that email. Nothing else leaves your phone. There is no analytics, no telemetry and no central server. The app is open source; you can verify this.
What if all three email providers fail? ›
The message is logged as ERR in the app's log screen. WorkManager will retry automatically (up to 6 times, with exponential backoff) in case of temporary server errors. Permanent failures (bad API key, unverified sender) are not retried.
Why not use Gmail / SMTP? ›
SMTP authentication from Android requires storing your full email password on the device and opening firewall ports both of which are security risks. REST APIs need only a revocable API token that grants only sending permission. API is much safer and works through any firewall.
